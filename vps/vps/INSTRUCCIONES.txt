TUACADEMIA EN EL VPS DEL ERP - TUKAN SOFTWARE (instalacion nueva)
=====================================================================
COMO QUEDA
  - TuAcademia corre APARTE de TuVocalia: otra carpeta, otro contenedor, otra base de datos.
      * Programa y datos:   /var/www/tuacademia      (respaldos en /var/www/tuacademia_respaldos)
      * PHP 8.5 en Docker:  contenedor "tuacademia-php" (puerto interno 9086)
      * nginx:              solo dentro del servidor en 127.0.0.1:8096 (TuVocalia usa 8095)
      * Direccion:          https://tuacademia.tukanec.com (provisional), por el tunel de Cloudflare
  - LIMITES para no afectar al ERP, a TuVocalia ni al SRT / Restreamer:
      * maximo 1 de los 6 nucleos y 1 GB de RAM, prioridad BAJA, 20 paginas por segundo por visitante
  - /var/www/tuacademia entra solo en el respaldo cifrado de cada noche (restic, 2:00 am) que ya copia /var/www.
  - La app de Google Play queda APAGADA (app/config.php: 'google_play' => false).

SI ALGO SALE MAL (apaga TuAcademia; el ERP y TuVocalia siguen igual), una linea a la vez:
  sudo docker stop tuacademia-php
  sudo rm -f /etc/nginx/sites-enabled/tuacademia
  sudo systemctl reload nginx

PASO 0 - Revisar (NO cambia nada). PuTTY en el VPS:
  cd
  git clone https://github.com/qfcorp/tuacademia.git
  sudo bash tuacademia/vps/vps/vps_0_revisar.sh
  -> Envie a Claude todo lo que salio (debe decir "Puerto 8096 libre" y "Puerto 9086 libre").
  (Si el repositorio es privado: primero  sudo gh auth login  o pida a Claude la llave de despliegue.)

PASO 1 - Preparar (hacerlo cuando NO haya transmision):
  sudo /usr/local/bin/git_backup_erp_qf.sh
  sudo bash tuacademia/vps/vps/vps_1_preparar.sh

PASO 2 - Instalar el programa (baja la ultima version de GitHub y crea la base nueva):
  sudo bash tuacademia/vps/vps/vps_2_codigo.sh
  -> La primera vez le pide el nombre, correo y clave del SUPERADMINISTRADOR.

PASO 3 - Publicar https://tuacademia.tukanec.com (navegador)
  1. https://one.dash.cloudflare.com > Networks (Redes) > Tunnels > el tunel del VPS (vps-erp) > Configure
  2. Public hostname > Add a public hostname:
       Subdomain: tuacademia   Domain: tukanec.com   Type: HTTP   URL: 127.0.0.1:8096   > Save
  3. Abra https://tuacademia.tukanec.com y entre con el superadministrador.
  4. Superadministrador > Ajustes: escriba el WhatsApp y el correo de ventas, y los datos de pago.

DIA A DIA EN EL VPS
  Ver como esta:                     sudo bash tuacademia/vps/vps/vps_estado.sh
  Actualizar a la ultima version:    cd tuacademia && git pull && cd .. && sudo bash tuacademia/vps/vps/vps_2_codigo.sh
  (vps_2_codigo.sh no toca la base de datos, las fotos ni app/config.php.)

CUANDO SE ELIJA EL NOMBRE DEFINITIVO
  - Cambiar SITIO en vps/vps/comun.sh y la marca en Superadministrador > Ajustes.
  - Agregar el nuevo subdominio en el tunel (como en el paso 3) apuntando al mismo 127.0.0.1:8096.

NUNCA correr en el servidor los scripts de pruebas/ (borran la base). vps_2_codigo.sh deja la marca data/.servidor para impedirlo.

CONECTAR CON EL PANEL TUKAN CENTRAL (panel.tukanec.com)
  1. Actualice el programa (trae el conector y deja el comando en /var/www/tuacademia/vps/):
       cd tuacademia && git pull && cd .. && sudo bash tuacademia/vps/vps/vps_2_codigo.sh
  2. Copie el comando que muestra el Panel Tukan Central para TuAcademia y peguelo en PuTTY del VPS:
       sudo bash /var/www/tuacademia/vps/conectar_central.sh ID SECRETO URL
     Debe terminar con:  OK: TuAcademia esta conectado al Panel Tukan Central
     Se puede repetir las veces que haga falta. No hace falta reiniciar nada.
  3. (Opcional) Que el superadministrador entre SOLO desde el panel central:
       sudo bash /var/www/tuacademia/vps/conectar_central.sh --solo-central 1
     Las academias, profesores y padres siguen entrando igual.
  Probar otra vez:     sudo bash /var/www/tuacademia/vps/conectar_central.sh --probar
  Apagar el conector:  sudo bash /var/www/tuacademia/vps/conectar_central.sh --desconectar
  EMERGENCIA (el panel central no funciona y necesita entrar como superadministrador):
       sudo bash /var/www/tuacademia/vps/conectar_central.sh --solo-central 0
     y entre con su correo y clave. Si ese super lo creo el panel central (no tiene clave), pongale una:
       sudo docker exec -it -u www-data tuacademia-php php /var/www/tuacademia/app/crear_admin.php
  La configuracion (con el secreto) queda en /var/www/tuacademia/data/tukan_central.env: no va a GitHub
  y entra en el respaldo cifrado de cada noche.
  PROTOCOLO V2 (el panel central ve y atiende solicitudes, clientes, pagos y finanzas):
    Viene con el codigo: basta con actualizar el programa (vps_2_codigo.sh). NO hay que volver a conectar.
    Comprobar:  sudo bash /var/www/tuacademia/vps/conectar_central.sh --probar
      debe decir "Protocolo v2: si" y cuantas solicitudes hay por atender.
    Si el panel central muestra "Solo cifras" para TuAcademia, el programa todavia es la version vieja: actualicelo.
    Lo que se hace desde el panel queda en la Bitacora del programa como "Panel Tukan Central".
    Suspender desde el panel es de verdad: Las academias suspendidas no pueden guardar cambios y su pagina publica se oculta.
  Que ve el panel central: las academias (sin la demo) en prueba, activas, por vencer, vencidas y suspendidas, lo cobrado
  por suscripciones, y alumnos activos, cursos, clases y asistencias del mes, pensiones cobradas del mes, profesores y usuarios.
  (vps_2_codigo.sh baja el programa de GitHub: el conector tiene que estar subido a GitHub antes del paso 1.)
